## ECS

Before I started this project I was working on building a very basic openGL game which I had given up on. In that project I had a basic ECS system built which I decided the transfer over to this project so it wouldn't be rendered useless. This system works with a sparse mapping where I have two arrays, a sparse array that maps the EntityIDs to an index and a dense array that stores the actual components. I decided to do it this way because I wanted to know how things work. Had I used a library like EnTT, I probably wouldn't have taken the time to properly understand what was going on.

This is also useful because I can create entities for all the chess pieces and then add all the components that they need to that specific entity. Below is an example on how I use the ECS to create a piece.
```C++:Components.hh
 struct ChessPieceComponent {
    PieceType type;
    PieceColor color;
    bool hasMoved;
    bool isCaptured;
  };

  struct BoardPositionComponent {
    int col;
    int row;
  };

  struct SelectionStateComponent {
    bool isSelected;
    bool isLegalMoveTarget;
    bool isLastMoveFrom;
    bool isLastMoveTo;
    bool isInCheck;
  };
```

```c++:example for creating pieces
ECS::EntityID e = m_Registry.CreateEntity();
m_Registry.AddComponent(e, ChessPieceComponent { type, color, false, false} );
m_Registry.AddComponent(e, BoardPositionComponent { col, row} );
m_Registry.AddComponent(e, SelectionStateComponent { false, false, false, false, false });
```

## What Has Been Done To This Day?

As of right now, a basic chess game is fully functional, albeit, I have to player for both colors and the pieces are currently letters and not their actual piece image. I have implemented piece movement, captures, promotions, capture promotions, en passant, and castling. We also have check/checkmate detection. The movement is fairly straight forward where we check the type of piece that was clicked and it's position. We then call a function to generate all the legal moves and returns a vector of all those legal moves. The move generation funtion generates all moves and also makes sure to not allow moves that would put your king in check.
