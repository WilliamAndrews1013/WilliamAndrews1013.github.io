## Introduction

This project was for a game jam where the theme was chain reaction. I was part of a team of 8 and 1 of 2 programmers.

## My Contribution

 My tasks for this 48 hour game jam was player movement and implementing a local co-op to the game. This was the first time that I decided to use Unity's new input system and the reason why I had chosen that was because it was easy to implement a local co-op function. Only to find out that it wasn't capable of splitting a keyboard and use 1 keyboard to control 2 players. So we ended up going with using a controller and keyboard. I realize afterwards that it would have been much better to use the old way to use inputs over the new input system. I spent most of my time trying to do basic movement and that was basically all I spent my time on on the first day of the game jam. After I finished that I transitioned over to helping making sure we had no merge conflicts and helped with the game design. Since most of the team I was working with were doing there first ever game jam and was the only one with game jam experience, I was making sure that the game scope wasn't getting out of hand. In the end even though I did more managing over actual programming, I was still happy with how the game came out and seeing people actually enjoy the game when testing out was more then enough to make me satified with the game.
